Usage Code Examples

Vue Component Usage:

<template>
  <DevChart 
    username="{{ githubUsername || 'your-username' }}"
    platform="github"
    theme="{{ githubTheme }}"
    output-format="{{ githubOutput }}"
    :width="900"
    :height="180"
  />
</template>

<script setup>
import { DevChart } from 'devchart-vue'
</script>

Direct API Usage:

import { getGitHubContribution, generateHeatmap } from 'devchart-vue'

// Fetch data
const data = await getGitHubContribution('{{ githubUsername || 'username' }}')

// Generate chart
const svg = generateHeatmap(
  data.data, 
  data.username, 
  data.summary,
  { theme: '{{ githubTheme }}', width: 900, height: 180 }
)
